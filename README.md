# 🎯 Number Guessing Game - JavaScript Project

This is a simple yet engaging number guessing game built using **HTML**, **CSS**, and **JavaScript**.

## 🌟 Features

- Random number between 1 and 100 generated.
- 10 attempts to guess the number correctly.
- Displays previous guesses and remaining attempts.
- Real-time feedback if the guess is too high or too low.
- Option to start a new game after completion.

## 🧠 What I Learned

- DOM manipulation in JavaScript
- Event handling using `addEventListener`
- Game logic using conditions and loops
- Updating UI dynamically based on user input
- Styling interactive elements with responsive design

## 📁 Files Overview

- `index.html` – Game structure
- `style.css` – Stylish UI with gradients, shadows, and layout
- `script.js` – Game logic and interactivity

## 🚀 Try it out

Just open the `index.html` in your browser and start guessing!
